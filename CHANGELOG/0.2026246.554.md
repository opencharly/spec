# 0.2026246.554 — feat(schema): vm box metadata contract — ai.opencharly.vm.box label + completeness gate

## Summary

Implements **task 2 of the VM-box cutover** (plan/vm-from-box-layering.md §2.1: "a VM box is an OCI image whose labels carry the VM metadata contract and whose layers carry the disk artifact") — the **VM box metadata contract** in the spec module. The container analog is `spec.BoxMetadata` ↔ `ai.opencharly.*` labels, completeness-gated by `TestCapabilityLabelCompleteness` (sdk/deploykit/capabilities_test.go); this PR lands the VM analog: a new `spec.VmBoxMetadata` carried whole-struct as ONE JSON label (`ai.opencharly.vm.box`), with its own completeness map + test. The box image also carries the standard BoxMetadata labels; VmBoxMetadata layers the VM-specific facts on top.

Changes (5 files, +269):
- **`schema/vm_box_metadata.cue`** (new) — CUE-sourced `#VmBoxMetadata` + `#VmBoxSource`, mirroring boxmetadata.cue conventions (package-less, closed, @go tags, per-field comments). Fields: distro, arch, base_user, ssh_user, firmware (bios|uefi-insecure|uefi-secure), init, charly_install (auto|scp|skip), version (CalVer), source (provenance: cloud_image|bootc|clone|bootstrap|iso + from_vm/from_snapshot/box/url), description, plan (reuses the existing `#Step` like #LabeledDescription does).
- **`spec/label_consts.go`** — `LabelVmBox = "ai.opencharly.vm.box"` (the whole VmBoxMetadata marshaled as one JSON label, like LabelService does for CapabilityService — R8-safe: a NEW label with no byte-freeze anchor).
- **`spec/cue_types_gen.go`** — regenerated via `task cue:gen` (exactly its output; +80 lines, `VmBoxMetadata` + `VmBoxSource` only).
- **`spec/vm_box_labels.go`** (new) — `VmBoxLabelMap` (field → LabelVmBox, the struct ↔ label sync table) + `CheckVmBoxLabelCompleteness()`.
- **`spec/spec/vm_box_metadata_test.go`** (new) — `TestVmBoxLabelCompleteness` (reflect over VmBoxMetadata fields; any field without a map entry fails) + `TestVmBoxMetadataLabelRoundTrip` (marshal a populated VmBoxMetadata → unmarshal → DeepEqual, proving the label wire round-trip).
