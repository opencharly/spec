# 0.2026271.743 — feat(spec)!: remove the now-dead RefsCollectSeams.LatestTag seam

## Summary

Remove the now-dead `RefsCollectSeams.LatestTag` seam field (and its compile-only guard test).

Version-less remote refs no longer resolve to the latest tag: the sdk's `CollectRemoteRefsOpts` (opencharly/sdk#317) now resolves a version-less ref to the repo's **DEFAULT BRANCH**. A version-less ref means "the current tip of that repo"; the old latest-tag behavior served a **stale build** that also **shadowed a project's explicit pin** for the same word (opencharly/charly#715). With that resolution change, `RefsCollectSeams.LatestTag` has **no reader anywhere**, so it is deleted here (R5 — no dead seam survives the cutover).

The `gitClient().LatestTag` method and the `GitLatestTag` primitive are unchanged — only the unused loader seam field goes (explicit tag resolution still uses them).
