# 0.2026322.1111 — feat(storeroot): add the data root ($XDG_DATA_HOME/charly)

## Summary

**`storeroot` had four roots, and the image store lives on a fifth.** W3.6 puts every built
image in ONE engine-neutral OCI layout at `$XDG_DATA_HOME/charly/images` — `plugin-build`'s
`imagestore.go` says so and names opencharly/sdk#458 as the reason it resolves the path by hand.
None of config, cache, state or runtime is that root, and both available alternatives are wrong:

- **the cache root** — `CHARLY_CACHE_DIR` relocates it, so an override meant to make a *cache*
  disposable would carry every built image into a tree the operator expects to be reclaimable, and
  a cache clear could delete a build's output. A cache is re-derivable by contract; a built image
  costs a rebuild.
- **resolving `$XDG_DATA_HOME` inside each consuming plugin** — the second roots resolver
  `storeroot` exists to end (`roots.go`: *"It is THE resolver: no caller builds a `.cache` path by
  hand."*).

So `RootData` is a fifth root, with no override, and `DataDir()` sits beside `CacheDir()` because
those two are the pair a caller actually compares: data when losing it costs a rebuild, cache when
it can be re-derived.

### Why now — measured on this host, 2026-11-18

The store had grown to **619 GiB across 1609 index entries**, and nothing in charly could reclaim
any of it:

```console
$ du -sh ~/.local/share/charly/images
619G

# index.json entries, and every blob no entry reaches
entries=1609  blobs=4557  total=701.6 GB
UNREFERENCED blobs: 292  bytes 37.24 GB
```

`charly clean --images` prunes the *engine's* local storage (`kit.ListLocalImages` → `<engine>
images`), while `charly clean --cache` reaches `spec/cache`'s config-root store and
`storekit.NamedStores()` under the **cache** root. Both `NamedStores()` and `StoreDir()` resolve
through `CacheDir()`, so the data-root store is structurally invisible to the sweep.

That is the chain this change starts:

| leg | issue | state |
|---|---|---|
| the fifth root | **this PR** — opencharly/sdk#458 | here |
| move the store layout into `storekit` | opencharly/sdk#460 | next |
| `keep_images` prunes the charly image store | opencharly/plugin-clean#21 | after sdk#460 |
