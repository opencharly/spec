## W2 — R3 duplication unification

Every audited duplication cluster is now one copy:

- **`StepContract` — three forms to one.** The string form (the capability package's
  hand-written struct) is deleted; `spec.StepContract` — the typed `Scope`/`Venue`/`Gate`/
  `Emits` struct — is the single canonical form. `capability.ProvidedCapability` now
  carries `*spec.StepContract`; the sdk root re-exports the typed form, so the ~92 plugin
  call sites compile unchanged.
- **`PollCondition`/`PollCond`** — byte-identical twins. `exec.PollCond` is deleted;
  `PollFunc` now takes `poll.PollCondition`, the one copy.
- **`SortedEnvPairs`/`EnvMapToPairs`** — the duplicate body in `proc/launch.go` is
  deleted; `EnvMapToPairs` has its one home (moved to `spec/proc` during the slice).
- **`CompareSemver`/`CompareCalVer`** — one comparator with prefix handling:
  `refs.CompareSemver` delegates to `calver.CompareCalVer`.
- **`Android`/`ResolvedAndroid` and `Distro`/`ResolvedDistro` method twins** — the
  `PrimaryFormat`/`LocalPkgFormat` pairs share a `primaryFormat` helper.
- **`StepKindName`/`StepKind` collision** — the candy-facing install-step-role constants
  are renamed `StepKindName*`, disambiguated from the internal `spec.StepKind` IR enum.

Two audit flags resolved as no-ops, with the reasoning recorded in the code:

- **`Phase`/`PluginPhase`** — nothing to rename: the `spec/phase` package's constants are
  already untyped strings (no named `Phase` type colliding with the IR `spec.Phase`).
- **`CLISubcommand`/`ProvidedCapability`** — documented authoring-vs-wire layering, not
  duplication: the authoring structs are the SDK-facing surface that `BuildCapabilities`
  marshals into the generated proto wire forms. The `capability.go` doc states it.

## W3 — R5 legacy deletion

Four legacy surfaces removed completely, each with its migration and grep self-test:

- **`CandyReader.LocalPkg` / `LocalPkgFormats`** deleted; the deprecated `localpkg:`
  field removed from `candymodel.cue`; a migration entry + `#SchemaVersion` bump carry the
  `localpkg:` → `packaging:` data forward.
- **`install_template` removed from `#Format`/`#Builder`** — the legacy `(install,
  container)` fallback the resolvers fell back to when `phase:` lacked the cell. The
  legacy arm in `phase_template.go` is deleted; content migrates into
  `format.<fmt>.phase.install.container` (a structural-reshape Go hook), with a migration
  entry + `#SchemaVersion` bump. The **retained** `#LocalPkg.install_template` /
  `#Bootloader.install_template` fields are distinct and untouched.
- **`DeployTarget` → `EmitTarget`** — a breaking rename, not a delete: the interface is a
  live two-method IR-emission contract (the retained build engines satisfy it), and its
  "legacy" label was a stale comment R5 requires sweeping. `UnifiedDeployTarget` and the
  CUE-sourced `DeployTargetDispatch*` types are unaffected.
- **`ResolveTunnelConfig` deleted** — zero production callers, unused params, plus its DI
  seam. `TunnelConfigFromMetadata`'s external consumers were verified before the delete.

Grep self-tests (word-boundary, working tree at commit): `PollCond`,
`ResolveTunnelConfig`, `capability.StepContract`, `LocalPkgFormats`, `spec.ShellQuote`,
`spec.EnvMapToPairs` all **CLEAN**; `DeployTarget interface` returns only the retained

  methods and `PodAwareMCPProvides` stay hand-written (behavior, not wire shape).
- **`DeployRecord`/`CandyRecord`/`StepRecord`** — CUE-sourced in `schema/deploy.cue`; the
  hand-written structs in `spec/ledger_records.go` deleted.
- **`EnvProvideEntry`/`ProvidesConfig`** — CUE-sourced.
- **`CheckHTTP*`/`CheckVerbResult`/`CheckGraphicsEndpoint`** — **SDD-AUDITED,

  without exception" does not reach them.
