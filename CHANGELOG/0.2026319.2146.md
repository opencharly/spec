# 0.2026319.2146 — feat(ir)!: the candy model carries data as opaque bytes

## Summary

The **third** of `#CandyModel`'s seven authored-shape fields to become opaque, on the pattern `hook` (`spec#331`) and `extract` (`spec#332`) established:

```cue
	data?: bytes @go(Data,type=RawBody)
```

`#CandyData` **stays** in `spec` — it is `#Candy`'s own field — and the IR stops **importing** it, carrying the JSON bytes instead (`DESIGN.md` §3.1, I1 / D-SCH-7).
