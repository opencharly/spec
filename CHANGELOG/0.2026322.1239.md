# 0.2026322.1239 — revert(storeroot)!: remove the data root — D-STORE-1 defines four roots

## Summary

**Reverses `spec#372`.** That PR added `RootData` (`$XDG_DATA_HOME/charly`) and `DataDir()` on the
premise that a built image is durable data rather than a cache item. `DESIGN.md` says the opposite,
and three rows read together say it precisely:

- **D-STORE-1** — the roots are configuration, cache (single override `CHARLY_CACHE_DIR`), state and
  runtime. Four. There is no data root.
- **D-STORE-3** — one content-addressed store holds every cached item, *including artifacts*, and
  "no other on-disk cache format exists".
- **D-STORE-7** — `charly clean` keeps what state references and evicts the rest within a size
  budget. That is how a built image's lifetime is defined, and it is exactly what the durability
  argument ("a cache is re-derivable; a built image is not") was reaching for.

So the fifth root was a contract violation introduced on a premise the contract rejects. Filed as
opencharly/opencharly#1098 by the sdk leg, which read the contract and found the code wanting.

**This is the producer step of the conformance cutover, not a retreat from the goal.** The store
itself moves under the cache root and becomes digest-keyed per D-STORE-3 / D-LAW-7 / D-FORM-2 in the
legs that follow, with `repo:tag` resolved to a digest before it reaches the store (D-STORE-5) and
the registry served as a view of its entries (D-STORE-10). Once that lands, nothing needs a data root
— so the root goes now rather than being left behind as unused surface (R5).

## Change classification

**Breaking change + rollback:** `storeroot.RootData` and `storeroot.DataDir()` are removed, so a
consumer of `v0.2026322.1111` that imported either stops compiling — that is `RootData` and
`DataDir`, and the only consumer in the org is opencharly/sdk#556, which is open, unmerged, and being
reworked to the conforming model in the follow-up leg, so nothing on `main` breaks. The rollback is
to revert this commit, which restores both symbols and the four-root prose untouched; the four
original roots resolve to exactly the paths they always did, in both directions.
