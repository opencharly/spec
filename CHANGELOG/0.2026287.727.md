# 0.2026287.727 — chore(schema): remove the eight inert #Kubernetes cluster-template fields (R5)

## Summary

Eight fields of the `kind: kubernetes` cluster template were **authorable and silently inert**.
`#Kubernetes` is CLOSED, so they validated, and nothing read them. For `secret:` that is worse than
a missing field — an operator writing

```yaml
secret: {backend: external-secrets, store: vault-prod, prefix: prod/}
```

got no `ExternalSecret`, no `secretKeyRef` wiring, and **no error**, while the schema comment read
as a live contract.

Removed, together with the six definitions that existed only to type them:

| Removed field | Definitions removed with it |
|---|---|
| `replica` | — |
| `resources` | `#KubernetesResources`, `#KubernetesResourceValues` |
| `hostnames` | `#KubernetesHostname` |
| `gateway_api` | `#KubernetesGatewayAPI` |
| `secret` | `#KubernetesSecretsBackend` |
| `observability` | `#KubernetesObservability` |
| `network_policy` | — |
| `plan` | — |

The per-deploy `plan` and the per-deploy `replica` are fields on a DIFFERENT type
(`#KubernetesDeploy`) and are untouched — that is the read set the one generator that consumes a
cluster template (`plugin-k8sgen`'s `opts.Cluster.*`) actually uses. A stale `secret` reference in
the `kubevirt` comment was corrected in the same edit.

**This alters AUTHORED wire keys**, so a consuming repo whose config still sets one gets a hard
`field not allowed` and `charly migrate` becomes its problem — declared here as this repo's
AGENTS.md requires, and measured empty below.

**Round 1 (head `b36342f6`)** answers the validator's round-0 verdict, which was fair on both
counts: the two sweep claims in R5 and in Change classification were prose, not executed evidence,
and a cross-repo obligation was described without a `BLOCKS`. Both are fixed here — the sweeps are
now run and pasted verbatim, and `opencharly/sdk#377` is filed and `BLOCKS`-linked from this thread
and from that one. The RCA, with the named missed control, is in this PR's round comment.

Closes #222
