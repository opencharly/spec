# 0.2026253.1700 — fix(schema): the deploy from: ref allows the namespace-qualified form (ns.entity)

## Summary

The deploy node's from: CUE regex (schema/deploy.cue) allowed only [a-z0-9]+(-[a-z0-9]+)* for the entity part — the namespace-qualified form (omarchy.check-charly-omarchy-vm, a git-linked import ref) was rejected at parse time even though the canonical reference-resolution surface (loaderkit ResolveEntityRef, sdk #246) resolves it. The entity part now allows dots: [a-z0-9]+([.-][a-z0-9]+)* — dots separate the namespace from the entity, hyphens separate words. The :snapshot suffix is unchanged.

**schema/deploy_from_test.go** (new): the shipped schema is compiled (schemaconcat) and #Deploy is unified with the from: literals — the namespace-qualified ref (the exact eval-omarchy X3 spike ref), the local NAME:TAG spelling, and three malformed refs (double dot, leading dot, trailing colon) that must be rejected.
