# 2026.238.0901 — feat: add the LatestTag seam to RefsCollectSeams (hermetic version-less ref resolution)

## Summary

The candy de-submodule cutover (Phase 4) resolves version-less remote refs to the repo's **LATEST TAG** (immutable) instead of the mutable default branch. The tag resolver (`spec/refs.GitLatestTag`, a `git ls-remote` shell-out) is registry-coupled, so it joins the existing seams (`Downloader`/`MigrateCache`/`ResolveLocal`) as a host-supplied callback — letting the loaderkit mechanism be unit-tested **offline and deterministically**, without live network access at test time.
