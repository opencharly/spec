# 0.2026317.2143 — feat(wire): the connected plugin entry carries its provider words, and ONE manifest format

## Summary

A delivered plugin TREE is a directory of provider binaries in which a bare command/verb WORD resolves only through a `<leaf>.providers` manifest beside the binary. **Measured 2026-11-13 on a disposable guest**: the tree was delivered, `CHARLY_PLUGIN_DIR` pointed at it, and `charly firecracker --help` still printed charly's USAGE text. Adding the manifest by hand made the same command resolve:

```
$ CHARLY_PLUGIN_DIR=/tmp/charly-plugins charly firecracker --help      # tree = binaries only
Usage: charly <command> [flags]
$ printf 'verb:firecracker\ncommand:firecracker\n' > /tmp/charly-plugins/plugin-firecracker.providers
$ CHARLY_PLUGIN_DIR=/tmp/charly-plugins charly firecracker --help
Usage: charly firecracker [<args> ...] [flags]
```

The engine has the words at connect time (`unit.Providers`, in scope at `loadPluginUnit`), so this leg carries them and gives the format ONE home:

- **`#DeployConnectedPlugin.providers?: [...string]`** — additive, optional: the words the connected unit serves, exactly as it declared them over Describe.
- **`spec.ManifestSuffix` / `spec.PluginManifest(providers)` / `spec.PluginManifestName(bin)`** — the ONE serializer. It has TWO writers (sdk/deploykit's baked-image emitter, and any class:step that delivers a tree), and they must produce the SAME bytes because the reader is one reader. A second `strings.Join` in the plugin would have been the third spelling of one format.
- **`spec/exec`'s `ManifestSuffix` now ALIASES `spec.ManifestSuffix`** — that package owns the tree probe and keeps its API, while the value lives in one place.
- **An empty word list renders NO manifest** (`nil`), because a zero-word manifest would satisfy a "does this tree carry a manifest" count while addressing nothing — the vacuous-tree class this format exists to prevent.

CUE-first: `schema/seam.cue` is authored, `spec/cue_types_gen.go` is generated, and a clean regeneration on the committed tree is a no-op (pasted below).
