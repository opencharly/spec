# 0.2026319.1619 — feat(schema): the resolve reply can carry diagnostics

## Summary

`charly box validate` prints the init-dependency warning and then reports **`0 warnings`** — the number a reader and a
landing gate take as the verdict. The RCA (opencharly/sdk#519) finally measured why, and it is a **missing wire field**,
not a missing reporter call:

| reply | carried diagnostics? |
|---|---|
| `spec.ValidateProjectReply` | **yes** |
| `spec.BuildResolveReply` | **no** — only `error: string` |

The namespaced-box fill (`deploykit.FillNamespaceBoxViews`, called from `plugin-build/resolve_legs.go`) runs under the
**resolve** reply. So the resolve had nowhere to put a finding its caller could count: the print reached the operator
through inherited stderr, and the count could not reach the summary that reports it.

**This adds the missing channel** — `diagnostics?: #Diagnostics` on `#BuildResolveReply`.

## How tested

Head `6c7742c` (`fix/resolve-reply-diagnostics` off fresh `origin/main`).

```console
$ charly -C . task cue-gen
  [pass] run — generate the Go params in-process + schemagen the vocab lists
  [pass] check — regen is reproducible — TestGenReproducible passes on the committed tree

$ go test ./...
  0 FAIL across the module
```

`spec/cue_types_gen.go` is a **pure regeneration** of `schema/buildresolve.cue` through the repo's own in-process
generator — no hand-written Go, and the reproducibility check passes, so a second run is a no-op.

**The consumer is deliberately not in this PR.** plugin-build's `fillNamespacedBoxes` records into the field and the
OpValidate path merges it, in a producer-first follow-up; without the field that follow-up is impossible, which is
exactly why the three earlier attempts (plugin-box, plugin-build/OpValidate, plugin-loader) could not work.

## Change classification

current producer compiles unchanged because the field is optional.

**Breaking change + rollback:** none — the field is optional and additive, so a producer that never sets it serialises
exactly as before. Rollback is the single commit.
