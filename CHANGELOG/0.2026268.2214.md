# 0.2026268.2214 — feat(schema): add the kubevirt substrate kind (6th deploy substrate)

feat(schema): add the kubevirt substrate kind (6th deploy substrate)

Adds `kubevirt:` as the 6th deploy substrate — a KubeVirt VirtualMachine on a Kubernetes cluster whose plan walks in the guest over SSH (the `vm` venue shape). Served out-of-process by the new plugin-kubevirt; this schema is the contract it and charly core both decode.

## Summary

- `#ResourceKind` gains `kubevirt`; `#KubevirtValue` added beside the other `#<Kind>Value` defs (schemagen auto-derives `KindValueDefs["kubevirt"]` — no hand map).
- New `schema/kubevirt.cue`: `#KubeVirt` (cluster/context/namespace, the **4-arm** `#KubevirtSource` boot medium — `container_disk` | `data_volume` | `pvc` | `clone` — domain shape, GPU host devices, firmware, network, instancetype/preference, run_strategy, migration, snapshot) plus its sub-blocks. Reuses `#VmCloudInit` for cloud-init (R3).
- `#Kubernetes` gains a `kubevirt:` cluster-policy sub-block.
- `substrate_template.cue`: `#ResolvedKubeVirt` + resolve input/reply.
- New `schema/kubevirt_client.cue`: the host↔plugin internal wire family.
- `#Deploy` gains the machine-written `kubevirt_state:` field (`#KubeVirtDeployState`, with `snapshot:` + `ephemeral:` matching the Go mirror); hand-written `KubeVirtDeployState`/`KubeVirtDeploySnapshot` in `spec/hand_state_types.go`.
- `KubevirtSource` hand-written in `spec/union_types.go` (the `VmSource` flat-union precedent).
- `#ProjectTemplates` gains `kubevirt` (opaque template map); `SubstrateKubevirt` status-kind const.
- `#SchemaVersion` bump note; regenerated `cue_types_gen.go` / `vocab_gen.go`.
