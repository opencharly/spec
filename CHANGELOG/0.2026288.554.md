**Why a knob was needed, measured on the tree that failed** (`distro-omarchy`'s `check-omarchy-pr-vm-anchored`, run `2026.288.0449`) — every step that consumes the change passed, and the run still reported `ok: false`, because the finalize's stop could not express the remedy its own message prints:

```
[snapshot-stop-keeper] FAIL after 3m0.476s: exit 1
charly: error: command "vm": VM charly-check-omarchy-pr-vm-anchored: did not reach a stopped state within
  the stop grace (still running) — use 'charly vm stop --force' if the guest ignores ACPI:
  stop domain charly-check-omarchy-pr-vm-anchored: poll: absolute cap exceeded (cap 3m0s)
```

**And the force path is safe, proven on a live `disposable: true` target before any of this was written:**

```
$ charly vm stop --force check-omarchy-pr-vm-anchored
Stopped VM charly-check-omarchy-pr-vm-anchored          # 38 s, where ACPI had failed for 3m0s
$ charly vm list | grep omarchy
charly-check-omarchy-pr-vm-anchored  libvirt  shut off  # shut off, still DEFINED
```

**The venue stays KEPT either way** — a force stop releases the process, not the domain definition — which is exactly what `snapshot-stop-keeper` is for (releasing the golden's exclusive qemu write lock after the capture).

**This is the producer leg of a four-leg cutover, and the chain is the reason it is one change:**

1. **spec (this PR)** — the field exists.
2. `plugin-check` — the keeper-stop step honours it, and falls back to a force stop when the graceful one fails, reporting which path it took.
3. `charly` — a pin bump, so the new step reaches a bed at all (plugin-check is compiled in).
4. `distro-omarchy` — the bed declares `force_stop: true`, and **its finalize is the single R10 witness for all four legs.**

The field is additive and optional, so **no authored wire key changes and no migration machinery is involved** (`AGENTS.md`: a pure `@go()` annotation preserves the wire key; the closed schema makes an unknown key a hard `field not allowed` error, which is why the producer must land before any consumer declares it — hence the order above).
