# 0.2026244.1013 — feat(schema): the snapshot-anchored check-run request fields (§5.3.1)

## Summary

Adds the anchored-mode request fields to `#CheckRunRequest` in `schema/seam.cue` (§5.3.1 of the omarchy PR-evaluation plan), with the regenerated Go struct fields in `spec/cue_types_gen.go`:

- `anchor` — the snapshot name to revert before the checks (the golden disk).
- `keep_venue` — keep the VM between runs for batch loops.
- `variant` — the VM-config variant name to boot over the shared golden disk.
- `vars` — per-run variable passthrough, e.g. `pr=9345`.

The `snapshot:`/`variants:` bed-policy blocks and the `#VmSnapshotPolicy`/`#VmVariant` types they build on were delivered in spec #86 (merged) — this PR adds the per-run request surface that `charly check run --anchor/--keep-venue/--variant/--var` will carry.

Regenerated `spec/cue_types_gen.go` via `task cue:gen`.
