# 0.2026269.138 — feat(schema): make a command's parent part of its capability identity

## Summary

A command capability's identity is `(class, word, parent)`. `charly box generate` nests
under `box`; a top-level `charly feature` is a **different** capability that happens to
share the word `feature`. The registry already knew this — it keys a nested command at
`command:<word>:<parent>` and a top-level one at `command:<word>` — but the **manifest could
not express the parent**: it lived only in the plugin's compiled Go (an optional
`CommandParent()` interface), never on the wire. The declaration was therefore lossy, and
an out-of-process nested command was impossible by construction.

This change makes the identity complete and declarative:

- **`#PluginCapability`** gains the command-only three-segment form
  `<class>:<word>:<parent>`. Only `command` may carry a parent — a `deploy:x:y` / `verb:x:y`
  is rejected by the type itself. The regex is composed from the two computed class patterns,
  never a hand-written alternation.
- **the wire** `ProvidedCapability` gains `command_parent`; `PluginRequirement`,
  `InvokeProviderRequest`, and `InvokeRequest` gain it too, so a declared peer and a
  transport name the full identity.
- **`spec/capability.ProvidedCapability`** and **`ops.InvokeProviderOpts`** carry it, and
  `opts.CommandParent` reaches `InvokeProviderRequest`.

The parent is now declared identically in every placement — compiled-in or out-of-process —
which is the whole point: a plugin following the spec is loadable without any core change.

## Rulebook compliance

- **SDD** — the authored form (`#PluginCapability`) and the wire shape (`command_parent`) are
  both CUE-owned; Go is regenerated, never hand-transcribed.
- **R2 (whole cutover)** — the parent is threaded through every transport that names a
  capability (ProvidedCapability, PluginRequirement, InvokeRequest, InvokeProviderRequest,
  ops.InvokeProviderOpts); no path is left expressing the word alone.
- **R5 (delete legacy)** — the two-segment-only `#ProviderClassPattern` is no longer the sole
  grammar; the command form is a first-class, type-enforced capability identity.
- **R7 (prove behavior)** — the schema test fails without the change and asserts the real
  emitted CUE grammar.
