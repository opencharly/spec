## Summary

Closes opencharly/spec#204 — the spec-side half of opencharly/sdk#315, and the last leg of that
cutover (the sdk half landed first, producer-first: opencharly/sdk#354, squash-merged `c2b7a1fc`,
tag `v0.2026280.2222`).

`spec.LocalPkgInstallStep.Version` has had no writer since that merge deleted
`deploykit/install_build.go`'s `Version: img.EffectiveVersion`, whose own producer
(`deploykit.ComputeEffectiveVersions`) died in sdk#313 — and it has no reader anywhere either:
`downloadLocalPkg` obtains the format's stable-latest `download_template`, never a versioned URL. It is
pure residue, and it is also a **guidance** defect: its doc claimed a behaviour the code never had.

**Deleted in this cutover:** the in-proc field (`spec/install_step_vocab.go`) **and** the doc line that
promised a versioned download; both round-trip assignments (`spec/install_step_view.go`, `StepToView` /
`StepFromView`), so the wire no longer pretends to carry a version; and the two fixtures that set it
(`spec/install_step_vocab_test.go`, `spec/install_step_view_test.go`).
