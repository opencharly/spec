# 2026.235.1905 — fix(fleet): CandyMapKey for the root-level remote candy (the candy de-submodule cutover)

## Summary

The candy de-submodule cutover's **root-level remote candy map key** (spec-side): a standalone candy repo's manifest lives at the repo ROOT (`SubPathPrefix ""`), so `CandyMapKey` must key it as the **repo path itself** — the previous derivation `RepoPath + "/" + SubPathPrefix + Name` doubled the name (`github.com/opencharly/layer-ripgrep/layer-ripgrep`), the overlay staging lookup missed, and `CandyCopySource` dereferenced a nil layer (the `check-pod-overlay` bed's deploy-add panic — the live evidence below). The sub-path form (a candy library inside a repo) is unchanged.
