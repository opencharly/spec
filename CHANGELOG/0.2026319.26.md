# 0.2026319.26 — feat(loader): the threaded seam carries a kind gate as DATA

## Summary

Successor to #323 (auto-closed at the verdict threshold with this same code; every block was body evidence, and this body now pastes the regeneration output too).

The RCA's step 3, contract half (`PROGRAM/schema-ownership-rca-rdd.md` §3 I2/I3/I4). A gate a plugin DECLARES must be reachable from a process that holds no plugin registry — which is exactly why `charly box validate` could not see a moved body.

`KindGate` carries the two things the receiving side needs: the CUE definition path the plugin declared, and the SERVED CUE source that declares it. `Threaded.KindGates` threads them as Clause-D data, so the loader compiles the source in its own context and looks the def up there — no registry query, no base fallback for a declared word, and no second private copy of the schema.

**Why this is needed now:** the vm body move exposed it live. `sdk/loaderkit.ApplyCueDefaults` resolved `#Vm` from the base schema, which no longer holds it, so six `applyCueDefaults` tests failed with `firmware: cannot convert non-concrete value string`. The SDK half of this cutover (`sdk#523`) resolves through the gates first.
