skills into the `ai.opencharly.skills` OCI label. The label constant this module defines is
`ai.opencharly.skill` — singular — and that is the only such key any built image carries:


  repo's own `charly task cue-gen`, never by hand.

**Nothing else moves.** No field, no `@go()` annotation, no wire key, no proto: this is a comment
