# 0.2026250.1815 — feat: thread the check-run candy source dirs on the CheckEnv wire (#CheckEnv.candy_dirs)

## Summary

Adds the optional `candy_dirs` map to `#CheckEnv` (CUE schema + the generated struct mirror, hand-updated in the generator's exact style) so the check-run's candy source-dir scan can cross the wire to the host-side committed-APK fixture anchor.

RCA: `checkhost.ResolveCommittedApk` (via charly's `resolveCheckApk`) resolves a relative `apk:` path against the AUTHORING candy source tree using the check carrier's CandyDirs map. The wire CheckEnv never carried the map, so an in-venue step of a baked live plan (pod-android-emulator-layer's `adb-install-apidemos` on check-android-emulator-pod) failed with "0 candies scanned" even though the plugin-side runner already folds `RunnerConfig.CandyDirs` (`candyDirsFromEnvelope`). Thread it: plugin-check emits it in its CheckEnv snapshot; charly's carrier decodes it.
