# 0.2026241.711 — feat(refs): GitClient — the centralized git layer with a persistent project-scoped cache

## Summary

Introduces `spec/refs.GitClient` — the centralized git layer that every loader git operation goes through, instead of each consumer running git commands itself (issues #423, #208).

- **Persistent cache**: `git-cache.json` under the project's charly dir (`.charly/cache`) or the repo cache dir, guarded by the advisory file lock.
- **TTL policy**: `LatestTag`/`DefaultBranch` 24h, `ResolveRef` 5m, mutable-ref `Download` 5m — a branch can move, but not on every invocation.
- **Loads the persisted cache on construction** — a warm cache is honored across invocations.
- **`WarmUp`** for the first-startup prefetch with user feedback.
- Freshness contract preserved: the primitive `GitResolveRef` stays uncached (live commits); the download TTL bounds mutable-branch staleness.
