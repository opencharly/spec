# 0.2026266.1306 — feat(schema): single-source the verb:oci cache-transfer wire types

## Summary

Single-sources the **verb:oci cache-transfer wire types** in CUE. The transport (candy/plugin-oci's `cache-push`/`cache-pull`) and its `charly cache push/pull` operator surface (candy/plugin-cache) each hand-wrote the same peer-dispatch JSON envelope — the drift risk R3 forbids. The existing OCI wire types (`#MergeRequest`/`#MergeReply`, `#ImageUserInput`/`#UserInfo`) are CUE single-sourced here in `schema/oci.cue`; the cache-transfer pair joins them:

- `#CacheTransferRequest { dir, ref, insecure? }` — the named cache's OCI Image Layout dir + the registry ref.
- `#CacheTransferReply { digest?, entries?, ref? }` — the resolved digest, the count of entry manifests moved, the canonicalised ref.

The Go structs (`spec.CacheTransferRequest` / `spec.CacheTransferReply`) are regenerated into `spec/cue_types_gen.go` by `task cue:gen`; both plugins will consume them (their own PRs, producer→consumer order).

**Files (2):** `schema/oci.cue` (+19), `spec/cue_types_gen.go` (+23, generated).
