# 0.2026320.1252 — feat(schema)!: the pipeline stage vocabulary -- DESIGN.cue's shape, transcribed

## Summary

**P26 unit 1 — the pipeline stage vocabulary**, transcribed from `DESIGN.cue:894-915` (the contract's own written shape), not invented:

```cue
#StageFields: { after?, when?, timeout?, retry?, on_error, lane?, concurrency }
#StageAlt:    { step? | pipeline? | deployment? | ask? }
#StageAsk:    { prompt!, answer! }
#Answer:      { expect?, unanswered: *"refused" | … }
#Retry:       { until?, attempt?, interval }
```

**Why it lands in `spec` first.** The stage shape is a **contract** shape. `plugin-pipeline`'s own schema header says its module may import only the contract module, so these defs land here and the plugin's `#Pipeline.steps` then becomes `stage: [...#Stage]` built from them. The ledger's P26 row had this order **inverted** (`plugin-pipeline > spec`) until the 2026-11-16 audit measured it; that row is corrected in the same wave.

**What was reused, not restated.** `DESIGN.cue` writes `step!: [...#DeploymentStep]` because it is a standalone document. This module already has that vocabulary as `#Step` (`00_common.cue:46`) / `#Op` (`:59`), so the step arm reuses it rather than restating forty defs (R2).

**Why it matters beyond this file.** `DESIGN.md:2996` refuses a second pipeline engine — *"the engine is the PIPELINE KIND's own implementation"* — and the flat `check-roster` kind, with its own `lanes` and worker pool, **is** one. With `after:` and `concurrency` on a stage, a roster becomes `stage: {<bed>: {deployment: […], after: […producers], concurrency: N}}`, which is `charly#1168`'s real fix: no new kind, no new field.

## Three measured deviations from DESIGN.cue's spelling

Each was **reproduced in a scratch schema before deviating**, and each is recorded in the file — a silent difference from the design would be the defect, a recorded one is not.

| `DESIGN.cue` writes | measured in this module | what it is here |
|---|---|---|
| `{step!: […], #StageFields...}` | postfix spread needs `@experiment(explicitopen)` | scheduling fields **hoisted onto the sum**, once |
| `{name!: T} & #StageFields` | `#<Arm>.<field>: field not allowed` — for every required name tried, **including `#StageAsk & #StageFields`** | same hoist; each arm is a pure payload |
| `#Stage: or([for _, a in #StageAlt {a}])` | same error; `close()` on each arm does not help | four optional arms; *"exactly one"* is a validation rule |
| `ask: {ask!: #StageAsk}` | a **required** field named `ask` cannot be unified with anything — `{zzz!: string} & #S` compiles, `{ask!: string} & #S` does not | the ask arm carries `#StageAsk` directly, one nesting shallower |

`TestTheStageVocabularyCarriesDesignsShape` **fails without the change** (the types do not exist) and pins the four properties that matter:

- a deployment stage decodes with its **`after:`** list and **`concurrency`** — the exact shape `charly#1168` needs the roster to become;
- the arms are **distinct** (a step stage carries no deployment and no prompt);
- `retry.attempt` is at **that level** — row 2.22 names it one level too high, and this is the test that would catch the drift;
- an **explicit** `answer.unanswered` round-trips, and a separate case proves **no authored value leaves the field empty** — the `*"refused"` default is a schema-layer fact this test does not claim (the same reason `retry.interval` is asserted with an explicit value).

Every field is **typed** in the generated Go, read from the file rather than inferred from the run:

```console

    grep -A2 "^type $t " spec/cue_types_gen.go | grep -c 'IncompleteKind'; done | sort -u
0
$ grep -c 'IncompleteKind' spec/cue_types_gen.go
```

`StageWhen` is `map[string]Matcher`. It was `map[string]any /* IncompleteKind */` in the first revision **because `#StageWhen` was defined twice in the file** — CUE unifies identical definitions silently, so the generator exited 0 while the type degraded. Removing the duplicate is what typed it; the review round's RCA records that. The dead `#StageAsking` alias is gone too.

**One assertion of mine was wrong and is corrected, not hidden:** I first asserted `retry.interval == "2s"`. It is `""`, because the `*"2s"` default is a **CUE-layer** fact and Go's decoder does not apply schema defaults. The test now round-trips an explicit interval instead.
