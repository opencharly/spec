# 0.2026254.503 — docs-config: closed CUE contract + generated types + loader classification for the docs: node

## Summary

Adds the docs-generation **configuration contract**: everything needed to configure docs auto-generation will live in a single `docs:` node in the charly repo's `charly.yml`. This PR provides the contract pieces:

- `schema/docs.cue` — the **closed `#DocsConfig`** CUE schema (with nested `#DocsSources`/`#DocsCompiled`/`#DocsMarketplace`/`#DocsProjections`/`#DocsOutput`/`#DocsLanding`/`#DocsGates`): compiled-plugin policy + paths, `release_repos` and `extra_repos` lists, marketplace corpus path, seven projection toggles, output/hand-authored markers, gates — defaults chosen so a minimal `docs:` node is valid.
- `spec/cue_types_gen.go` — **generated** Go types (`spec.DocsConfig` + 7 nested) via `task cue:gen` (the repo's SDD chain), committed generated code.
- `schema/docs_config_test.go` — closedness corpus: minimal + full configs validate; unknown fields and wrong types are rejected.
- `spec/docs_config_test.go` — unified-loader classification: `ClassifyDoc` routes the `docs:` node like `marketplace:`/`skill:`/`hook:` (no special-casing, R3); the `#NodeDoc` gate accepts it; the generated types round-trip.
