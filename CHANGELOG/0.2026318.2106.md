# 0.2026318.2106 — feat(wire)!: the load wire carries opaque bytes, never an authored body

## Summary

First cutover of the schema-ownership mechanism diagnosed in `PROGRAM/schema-ownership-rca-rdd.md`. The RCA's root cause: the cutover treated the wire's shape as a constraint on the kind instead of as part of the cutover, so every kind whose wire named an authored type stayed in this contract and was recorded as a "keeper". Ten entities are still in that state.

**This change removes the permission slip.** Both authored-type channels on the load wire now carry bytes:

- `#StructuralKindLoadEnv.members`: `{[string]: #Deploy}` becomes `{[string]: bytes}`;
- `#StandaloneLoad`: `shape` plus exactly one of `deploy` / `template` / `box` / `candy` becomes `shape` plus one opaque `body`.

Consequences, deliberately: the contract no longer carries `#Deploy`, `#Box` or `#Candy` on a wire at all — which is what makes their moves possible (DESIGN.md §3.1 puts the candy body and boxes in the build plugin, and the deployment kinds own their kind state). A consumer that needs a field decodes the bytes into its own CUE-declared value or the contract's projection; none receives the authored node.

`shape` keeps its four existing values (`deploy`, `template`, `candy-image`, `candy-layer`), so the wire's discriminator is unchanged and only the carrier moves.

## Change classification

Kind: a contract wire reshape. `#StandaloneLoad` and `#StructuralKindLoadEnv.members` stop carrying authored types; `deploy`/`box`/`candy`/`template` collapse into one `body` bytes field. Not breaking for the YAML author — no authored shape or field name changes — but it IS a breaking Go/protocol change for every plugin that reads those fields.

**Breaking change + rollback:** every plugin reading `Standalone.Deploy/Box/Candy/Template` or `Members[...]` as a node stops compiling until it echoes or decodes `Body`. After this merges, a consumer that has not yet bumped its `spec` pin stays on the previous contract (the `behind` state the pin contract reports) and keeps working; the four first-party readers are the ones that must bump to use the new shape. This contract's own `main` is green; what is already broken on `main` today is `plugin-k8sgen`'s pin (#1026), which this change neither causes nor fixes. Rolling back is reverting this squash: the four typed arms and the `#Deploy` map return, and every plugin compiles again because no authored body moved.
