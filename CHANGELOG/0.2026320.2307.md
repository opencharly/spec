# 0.2026320.2307 — fix(schema): #AuditDetail.value? projects a POINTER, so an absent marker is absent

## Summary

**An optional field that is never absent on the wire is not optional.**

`#AuditDetail.value?` generated as a struct **value**:

```go
Value Redacted `yaml:"value,omitempty" json:"value,omitempty"`
```

`encoding/json`'s `omitempty` **cannot omit a struct**, so a detail carrying no marker serialized as:

```json
"value": {"redacted": false}
```

That asserts *"not redacted"* on a record that simply had no marker — and a reader could not tell **absent** from **explicitly false**, which is the distinction `?` exists to make. Now:

```go
Value *Redacted `yaml:"value,omitempty" json:"value,omitempty"`
```

**Not a D-AUDIT-3 leak either way** — `#Redacted` has one field, a `bool`, so the marker can only ever be `true` and no secret value can sit there. The defect is the lost `?`, not the guarantee.

## Where the fix belongs, and why it is here

The annotation is the fix, **not** a second serializer in the consumer:

```cue
value?: #Redacted @go(Value,type=*Redacted)
```

`@go(<Name>,type=*<Type>)` is the same optional-struct spelling `schema/agent_control.cue` already uses for `target?`/`terminal_profile?`. A consumer-side `MarshalJSON` would be a second spelling of a schema fact — the duplication `R2` forbids, and the kind that drifts the moment the schema changes.

**Found by the sdk writer, not by me.** It hit the discrepancy against the merged contract and reported it as a contract-side finding rather than working around it locally: *"The fix is a pointer for an optional struct in the generator, not a second serialization in my package."* That is the right attribution.

## Change classification

Kind: a corrected `@go` annotation on an optional struct, and the regenerated type.

**Breaking change + rollback:** `AuditDetail.Value` changes from `Redacted` to `*Redacted`, which is a Go-source break for any consumer that set it — and it makes the wire honest, since a detail with no marker now omits the key. No consumer exists yet: `sdk`'s `auditkit` is written against exactly this shape and is not merged. Rollback restores the value type and the `?` is lost again.
