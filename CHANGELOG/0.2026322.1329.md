## Summary

`#Marketplace`'s comment in `schema/marketplace.cue`, and the generated doc comment in `spec/cue_types_gen.go`, described the corpus generator's output in two ways that no longer hold:

- **".mcp.json (when mcp_servers is non-empty)"**: opencharly/plugin-marketplace#62 (for #61) now emits `.mcp.json` only for **public** servers. A server whose URL host is local is served by a charly pod while it runs and is never wired into the static harness config.
- **"and the .claude/settings.json plugin-owned keys"**: the generator retired that write (`plugin-marketplace` `generate.go`: "longer writes charly's harness surface … the .claude/settings.json merge"). The `settings?`/`#MarketplaceSettings` field itself stays: `plugin-harness-kind`'s schema and the umbrella's `DESIGN.cue` still reference it.

The `mcp_servers?` field comment now says that only the public entries reach `.mcp.json`. The changes are comment-only. No shape, key or `@go()` annotation changed, and the generated Go was regenerated with `charly task cue-gen`.

The branch was BEHIND `main` after #375 (the storeroot revert), with a passing verdict on `95ff057903106ae0fde49a309370d310b89e2b62`. It catches up through a local merge commit, which touches no file this change edits, and the evidence below is re-taken on the merged head.
