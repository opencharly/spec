# 0.2026250.632 — feat(schema): #Packaging systemd units + config file, and the layered config-stack merge wrapper

## Summary

Two coupled changes from the systemd-units + /etc/charly config plan (plan/charly-mcp-systemd-config.md, §3.2 + §3.5), plus one in-tree test-robustness fix the validator's R1/R2 gate surfaced:

1. **Schema (§3.2)** — `#Packaging` gains two fields (after `formats:`):
   - `systemd?: [...#PackagingSystemdUnit]` — non-autostarting systemd units shipped in the package (system + user scope), rendered to `/usr/lib/systemd/{system,user}/<name>.service`, NEVER enabled at install.
   - `config?: #PackagingConfig` — a system-wide project charly.yml shipped in the package (e.g. `/etc/charly/charly.yml`) carrying the plugin config the systemd MCP server uses.
   Two new CLOSED sub-shapes: `#PackagingSystemdUnit` (name/scope/exec/description?/restart?/after?/wants?/environment?/working_directory?) and `#PackagingConfig` (path/version/description/plugins?).
   Regenerated via `task cue:gen`: `Packaging` gains `Systemd []*PackagingSystemdUnit` + `Config *PackagingConfig`; the two new Go types exist in spec/cue_types_gen.go.

2. **Merge wrapper (§3.5)** — `merge.MergeConfigStack(system, user, project, systemDir, userDir, projectDir)` merges the layered config stack (system → user → project) into one `spec.UnifiedFile`, LATER files winning (project > user > system). Reuses `MergeUnified` (dst-wins) with the later file as dst — no new merge logic (R3). Each layer's Discover specs are pre-anchored to its own dir via `spec.AnchorScanSpecs` before merging (so MergeUnified's srcDir re-anchoring is a no-op); each layer is copied before merging (caller files never mutated); nil layers are skipped.

3. **In-tree proc test fix (R1/R2)** — `proc/temphold_test.go` `altTempRoot` required a checkout NOT under /tmp (its premise: a temp root the sweeper's hardcoded "/tmp" glob does not cover). A worktree under /tmp broke that premise and the two `HonoursTMPDIR` tests failed. Fixed in-tree: `altTempRoot` now falls back to `/var/tmp` (still outside the hardcoded "/tmp" glob) when the package dir is under /tmp — the premise holds from any checkout location. Full suite is green from the /tmp worktree.
