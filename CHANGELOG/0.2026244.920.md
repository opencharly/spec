## Summary

Adds the snapshot-anchoring policy and the per-test VM-config variants to the deploy schema (§5.3.1 of the omarchy PR-evaluation plan):

- `snapshot: {on_finalize, reset_before_check, mode (internal|external), consistent, keep_venue}` — capture at install finalize and reset before every check run, so a batch of PR runs shares ONE golden disk (revert ≈ seconds vs fresh install ≈ 20-30 min). VM-only.
- `variants: {name: {cpus, memory, video, gpu, display, devices, attachments}}` — named VM-config overrides that boot the SAME golden disk with a different shape. A variant may ONLY change VM shape; any change to `source:` or disk identity is rejected at validate time.
